Your SummerCart64, finally under control

Manage ROMs & saves on your SummerCart64

A cross-platform desktop GUI built on the Summer Breeze CLI. Deploy straight to the cart, back up saves, update the SC64 menu, sync the RTC and browse the SD card — all in one dark, themeable app.

Thirteen screens, one cart

Every operation the Summer Breeze CLI can do, wrapped in a GUI — from status checks to firmware updates.

Status

Live sc64deployer info dump — firmware, RTC, save type, CIC seed, TV type, ROM config and SD card state.

Local ROMs

Import .z64, .n64 and .v64 files with N64 header validation and deduplication by game identity.

Cart Contents

See exactly what is stored on the SD card and which folders your ROMs live in.

Compare

Find which local ROMs are missing from the card so you can sync before a session.

Upload ROMs

Batch-upload local ROMs to any folder on the SD card.

Deploy to Cart

Flash any local ROM straight into the cart — optionally carrying a save, with a backup of the current one first.

Quick Upload

One-click upload straight to the SD card root.

Save Manager

Per-game save history, sync with the SD card’s /saves folder and restore by deploying with a ROM.

Update SC64 Menu

Fetch the latest official or custom sc64menu.n64, validate it and flash it with backup.

Background Music

Set menu music with the custom menu build — MP3s from the app’s menu_music folder.

Sync RTC Clock

Set the cart’s real-time clock from your system time.

Browse SD Card

An interactive file browser for exploring the SD card without leaving the app.

Console

A live, persisted log of the bridge’s output with copy/export — deploy failures are always explainable.

Make it yours

Fourteen themes, including the Gallery Glass family with nine photo backgrounds — switch instantly from a dark tech console to your favourite scenery.
